# v3

公開日: 2026-06-15

## 目的

シグナル単体の騰落率だけでなく、市場平均との差、取引コスト、資金配分、
候補抽出経路、市場環境を含めて、実運用に近い形で評価できるようにする。

## 実運用評価

- yfinanceの `^TOPX` をTOPIX代理系列として利用する。
- 1・3・5・10営業日の通常リターン、翌営業日寄付買いリターン、
  TOPIX超過リターンを保存する。
- 0・10・25・50bpの片道コストを買いと売りの双方へ適用する。
- 調整後終値と終値の比率をOpen・High・Low・Closeへ適用し、
  株式分割・併合をまたぐ追跡値の不連続を抑える。

## 仮想ポートフォリオ

- 毎日厳選を翌営業日寄付で等金額建てする。
- 各日コホートを5営業日保有する。
- 既定の取引コストは片道10bp。
- 累積収益、TOPIX収益、超過収益、最大ドローダウン、Sharpe、
  売買回転率、現在の仮想保有を出力する。

これは100株単位、税金、指値約定、寄付の市場インパクトを再現する
証券会社レベルの回測ではない。

## 候補ユニバース比較

正式な注目Top100は従来どおりYahooランキング候補から作成する。
実験群として、JPXプライム普通株を20日平均売買代金で順位付けした
上位600銘柄から別のTop100を作成する。

両群は別の `universe_source` で保存し、同じ将来収益、TOPIX超過収益、
コスト後収益で比較する。実験結果は自動で主候補群へ反映しない。

## 市場環境とリスク

- TOPIXの20日・60日移動平均位置、20日騰落率、20日変動率。
- 流動性上位銘柄の20日上昇比率、60日線上比率。
- 毎日厳選の平均変動率、銘柄間平均相関、最大業種比率。
- 上記から「積極」「中立」「慎重」と日本語の運用方針を表示。

## 互換性

- `top100.csv` と `daily_picks.csv` の正式な候補抽出元は変更しない。
- v1・v2の評価観測を保持し、v3観測は `evaluation_version=v3` で追加する。
- 過去スナップショットと公開済み版文書は変更しない。

## 既知の制限

- `^TOPX` は無料データ上の代理系列であり、JPX公式配信値との完全一致を保証しない。
- 流動性実験群は更新時間を抑えるためJPXプライム普通株を走査対象とする。
- 比較開始直後はv3の確定サンプルが不足する。
- 財務情報、決算予定、適時開示、ニュースはまだ評価へ含めない。
