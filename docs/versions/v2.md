# v2

公開日: 2026-06-15

## 目的

現行ルールと各因子の将来成績を継続的に観測し、十分な実績データに基づいて次版の改善候補を判断できるようにする。

## 変更内容

- Top100選定時点の因子値、ルール通過状態、評価版を履歴へ固定。
- 1・3・5・10営業日の将来リターンをTop100全銘柄について追跡。
- 因子を日次横断で五分位化し、上位分位と下位分位のリターン差を集計。
- 日次Spearman Information Coefficientを全体・業種別に集計。
- 期待方向上位分位の連続営業日入替率を集計。
- ルール通過群と未通過群の平均、中央値、勝率、平均差、95%信頼区間を集計。
- 最低30件の確定サンプルに達するまで「サンプル不足」と表示。
- `exchange_calendars` の `XTKS` を東証営業日判定へ導入。
- Streamlitへ「ルール・因子評価」タブを追加。

- `data/history/evaluation_followups.csv`

## Alphalensとの関係

日次運用では、Alphalens Reloadedの中心概念である収益分析、IC分析、入替率、グループ分析をPandasで軽量実装する。研究用ティアシートを試す場合だけ、次を追加でインストールする。

```powershell
python -m pip install -r requirements-research.txt
```

参考: https://github.com/stefan-jansen/alphalens-reloaded

## 互換性

- v1の候補履歴、Top100履歴、毎日厳選履歴、追跡履歴は保持する。
- ルール・因子評価は `evaluation_version=v2` の観測から開始する。
- 過去のv1スナップショットは変更しない。

## 検証

- オフライン単体・統合テスト18件。
- Python構文確認。
- `git diff --check`。

## 既知の制限

- 初期は将来リターンの確定数が少ないため、改善判断には使用しない。
- TOPIX超過収益、売買コスト、ポートフォリオ資金配分は今後の版で追加する。
- Alphalens Reloaded本体のティアシートは日次画面では自動生成しない。
