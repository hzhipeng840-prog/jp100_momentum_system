# v5

公開日: 2026-06-17

## 目的

GitHub Actionsの日次実行で、yfinanceの無料日足が対象営業日まで反映されていない場合に、
失敗として赤く残すのではなく、未公開のまま正常スキップして次の実行で再確認できるようにする。

## 変更

- 価格基準日不一致を専用例外として扱う。
- 取得日が期待日より古い場合は `price_not_ready` としてスキップし、状態JSONへ理由を残す。
- 取得日が期待日より新しいなど不自然な不一致は、引き続き失敗として扱う。
- 19:17・21:47（日本時間）の通常確認に加えて、次日08:17（日本時間）の再確認を追加する。
- 画面上の欠損率や欠損リターンを `+nan%` ではなく `―` と表示する。

## cron補助の判断

外部PCや自宅サーバーのcronは導入しない。GitHub Actionsの `schedule` 自体がcronであり、
今回の失敗原因は起動手段ではなく、無料価格データの反映遅延である。
そのため、同じActions内で再確認時刻とスキップ判定を整える方針とする。

## 互換性

- 評価式、Top100、毎日厳選条件、CSV出力構造はv4から変更しない。
- `price_not_ready` の実行では `data` ブランチを更新しない。
- 既に同一基準日・同一版が完了済みの場合は、従来通り `already_completed` でスキップする。

## 検証

- 価格データ未反映時の正常スキップを単体テストで確認。
- 不自然な価格日付不一致が失敗扱いになることを単体テストで確認。
- 既存のクラウド実行、履歴公開、評価、画面表示を含むオフラインテストを実行する。

## 既知の制限

- yfinance、Yahoo!ファイナンス、JPXのサイト仕様変更や通信障害は引き続き発生し得る。
- GitHub Actionsのスケジュールは指定時刻から遅延する場合がある。
- 08:17の再確認でも無料データが未反映の場合、その日は未公開のまま次回実行を待つ。
