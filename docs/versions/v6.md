# v6

公開日: 2026-06-17

## 目的

Streamlit画面から同じ日の「最新データを取得」を繰り返し押した場合に、
yfinanceの大規模な再取得を毎回走らせず、完了済みの結果をすぐ表示できるようにする。

## 変更

- 同じ基準日、同じシステム版、同じYahoo取得ページ数、同じ毎日厳選数で、
  かつ鮮度判定が有効な結果が存在する場合は再取得を省略する。
- サイドバーに「完了済みでも再取得する」チェックボックスを追加する。
- 強制再取得を選んだ場合だけ、JPX・Yahoo・yfinanceへ再アクセスする。

## 互換性

- 評価式、Top100、毎日厳選条件、CSV出力構造はv5から変更しない。
- GitHub Actionsの日次更新挙動はv5から変更しない。
- 既存の `data/processed/metadata.json` と `freshness` 情報を利用して判定する。

## 検証

- `app.py` を含む構文確認。
- 既存のクラウド実行、履歴公開、評価、画面関連データを含むオフラインテスト。

## 既知の制限

- 初回更新、新しい基準日、バージョン変更、取得設定変更、強制再取得では従来通り数分かかる。
- yfinanceが特定銘柄やTOPIX基準データを返さない場合、端末ログへ警告が表示されることがある。
