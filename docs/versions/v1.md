# v1

公開日: 2026-06-12

## 目的

日本株の注目Top100と毎日厳選3～5銘柄を、無料データだけで継続生成できる最初の正式版を構築する。

## データソース

- JPX: 東証上場普通株の正式な銘柄範囲、名称、市場、業種。
- Yahoo!ファイナンス: 値上がり率、出来高、出来高増加率ランキングの候補抽出。
- yfinance: 日足OHLCVと調整後終値。

## 評価

- 20日、60日、120日モメンタム。
- 20日、60日移動平均からの距離。
- 平均売買代金と直前20営業日に対する当日出来高倍率。
- 120日高値からの距離。
- 20日年率換算ボラティリティ。
- 候補内百分位による説明可能な合成スコア。

## 毎日厳選

- 注目Top100のみを対象とする。
- 最低株価、平均売買代金、上昇トレンド、過熱度、変動率を確認する。
- 原則として同一業種は1銘柄に抑え、3～5銘柄を選ぶ。

## 履歴と検証

- 候補出現回数、連続出現回数、Yahoo順位変化を保存する。
- シグナル日の終値を記録する。
- 翌営業日寄付を実行想定とし、1、3、5、10営業日後を追跡する。
- 平均リターン、中央値、勝率を全体、市場、業種、Yahoo順位帯別に集計する。

これはシグナル統計であり、資金配分、100株単位、手数料、スリッページを含む正式なポートフォリオ回測ではない。
